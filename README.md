# Forge

Forge is an open-source content-addressed version-control and distribution
system designed for massive datasets and binary artifacts.

The project is currently in early development.

## Vision

Forge aims to make version control practical for data ranging from gigabytes
to terabytes while providing efficient deduplication, integrity verification,
partial access, and eventually peer-to-peer distribution.
